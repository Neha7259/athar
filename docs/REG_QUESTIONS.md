# REG_QUESTIONS.md — Open regulatory questions

Per working agreement §12: when unsure about a regulatory field, do not invent — log it here.

## Received reference files

The repository contains ten EDD workbooks under `docs/edds/`, covering air, ambient water, liquid discharge, groundwater, waste, soil, marine sediment, ecology, annual resource consumption, and restricted chemicals. These are useful EAD environmental reporting references, but they are not the MOCCAE GHG/IEQT submission template.
